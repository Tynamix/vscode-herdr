# Support

Report bugs and request features at [Tynamix/vscode-herdr issues](https://github.com/Tynamix/vscode-herdr/issues).

For a bug report, include your operating system, VS Code version, Herdr Workbench version, herdr version, affected agent CLI and the steps needed to reproduce the problem. The **Herdr Workbench** output channel in VS Code can help identify the failing action. Review logs before sharing them and remove credentials or private project content.

Herdr Workbench is an independent extension for herdr. Agent authentication, model availability and agent-specific behavior are configured in the corresponding CLI.
